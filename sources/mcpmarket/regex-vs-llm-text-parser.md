# 正则 vs LLM 文本解析器

> Optimizes structured text extraction by combining high-speed regex patterns with LLM-powered edge case validation.

## 概述

Regex vs LLM Text Parser 通过组合高速正则模式与 LLM 驱动的边界情况校验,优化结构化文本提取的性能与准确率。

## 使用场景

- 从日志/半结构化文本中批量提取字段
- 对正则难以覆盖的边界用 LLM 兜底
- 降低纯 LLM 解析的延迟与成本

## 能力说明

- 正则优先 + LLM 兜底的混合策略
- 可配置的置信度阈值与回退机制
- 结构化(JSON)输出

## 风险与注意事项

LLM 兜底路径带来额外成本与延迟,需在 SLA 内合理调度。
