# 文档查询(Context7)

> Fetches real-time, up-to-date documentation and API references for modern libraries and frameworks using the Context7 MCP.

## 概述

Documentation Lookup (Context7) 通过 Context7 MCP 获取现代库与框架的实时、最新文档和 API 参考,避免 LLM 使用过时知识,显著降低幻觉。

## 使用场景

- 查询最新版本的库 API 签名
- 获取当前最佳实践的官方示例
- 对比不同版本的 breaking changes

## 能力说明

- 基于 Context7 MCP 的实时文档检索
- 支持主流前端/后端/云原生库
- 返回带版本号的权威片段
- 可直接嵌入 Claude 对话减少幻觉

## 风险与注意事项

依赖 Context7 服务的覆盖度与可用性;冷门库可能未收录。
