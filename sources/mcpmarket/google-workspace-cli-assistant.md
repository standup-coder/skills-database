# Google Workspace CLI 助手

> Integrates Google Workspace services like Gmail, Calendar, Drive, and Sheets directly into your terminal workflow.

## 概述

Google Workspace CLI Assistant 将 Gmail、Calendar、Drive、Sheets 等 Google 生产力服务集成到终端工作流,让你在 Claude 中直接读写邮件、管理日程、操作文档。

## 使用场景

- 终端快速检索与回复 Gmail 邮件
- 查询/创建日历事件并避免冲突
- 批量读写 Google Sheets 作为轻量数据库
- 在 Drive 中按内容搜索文件

## 能力说明

- 覆盖 Gmail、Calendar、Drive、Sheets 主要 API
- 通过 OAuth 与 Google 账号安全授权
- 支持自然语言指令转换为 API 调用
- 可与其他终端工具(如 git、make)组合

## 风险与注意事项

需要配置 OAuth 凭据并授予相应 scope;读写邮件/文档涉及隐私,建议使用专用账号并最小化权限。
