# 编码代理编排器

> Delegates complex development tasks and feature builds to specialized background AI agents like Codex and Claude Code.

## 概述

Coding Agent Orchestrator 把复杂的开发任务和功能构建委派给后台运行的专用 AI 代理(如 Codex、Claude Code),让你能并行推进多个子任务并统一汇总结果。

## 使用场景

- 并行实现多个独立功能模块
- 把研究、实现、测试拆分给不同代理协作
- 长时间运行的重构任务托管到后台

## 能力说明

- 支持委派给 Codex、Claude Code 等多种后台代理
- 任务队列、状态跟踪与结果汇总
- 可定义代理间的依赖与产出契约
- 失败任务可自动重试或人工介入

## 风险与注意事项

并发代理会显著消耗 token 与计算资源;建议设置预算上限并对代理可访问的资源做沙箱隔离。
