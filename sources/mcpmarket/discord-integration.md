# Discord 集成

> Manages Discord operations including messaging, reactions, and channel management directly through Claude.

## 概述

Discord Integration 让 Claude 直接管理 Discord 操作,包括发送消息、添加反应表情、管理频道与角色等,适合社区运营、自动化通知和互动场景。

## 使用场景

- 社区运营:自动欢迎新成员、回答常见问题
- CI/CD 通知:构建或部署结果推送到指定频道
- 内容审核辅助:批量清理垃圾消息或管理角色

## 能力说明

- 发送与回复消息、添加表情反应
- 频道与角色管理(创建、归档、权限调整)
- 支持与 Discord Bot Token 集成进行鉴权
- 可在对话流中直接调用,无需切换上下文

## 风险与注意事项

涉及 Bot Token 与频道权限,需妥善保管凭据并遵循 Discord 服务条款,避免被用于滥发消息。
