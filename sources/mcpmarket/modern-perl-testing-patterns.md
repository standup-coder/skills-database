# 现代 Perl 测试模式

> Implements comprehensive Perl testing strategies using TDD, Test2::V0, and advanced coverage analysis.

## 概述

Modern Perl Testing Patterns 实现全面的 Perl 测试策略,基于 TDD、Test2::V0 现代测试框架与高级覆盖率分析,帮助遗留 Perl 代码逐步走向可测、可维护。

## 使用场景

- 为遗留 Perl 模块补充单元测试
- 用 Test2::V0 重写老旧 Test::More 测试
- 接入 Devel::Cover 做覆盖率门禁

## 能力说明

- Test2::V0 现代断言与测试组织
- TDD 红-绿-重构流程
- Devel::Cover 覆盖率采集与报告
- Mock 与子测试(subtest)组织复杂场景

## 风险与注意事项

Perl 生态工具链较老,CI 镜像与依赖管理需要额外配置。
