# Homelab Pi-hole DNS 管理器

> Configures and manages network-wide ad blocking, DNS-over-HTTPS, and local network name resolution for homelab environments.

## 概述

Homelab Pi-hole DNS Manager 配置并管理家庭实验室的全网广告拦截、DNS-over-HTTPS 与本地网络名称解析,是 #23 的管理向增强版本。

## 使用场景

- 管理多台 Pi-hole 节点的高可用
- 统一维护黑白名单与分组策略
- 为内网服务暴露稳定本地域名

## 能力说明

- Pi-hole 集群/高可用管理
- blocklist 白/黑名单分组
- DNS-over-HTTPS 与本地解析编排

## 风险与注意事项

单点 DNS 故障影响全网,建议双机热备或保留 ISP DNS 作为回退。
