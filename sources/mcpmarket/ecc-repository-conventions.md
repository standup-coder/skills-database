# ECC 仓库规范

> Enforces standardized development patterns, commit formats, and architectural conventions for the Everything Claude Code ecosystem.

## 概述

ECC Repository Conventions 为 Everything Claude Code(ECC)生态强制一套标准化的开发模式、提交格式与架构约定,保证多个仓库风格一致、可维护。

## 使用场景

- 统一 ECC 多仓库的 commit message 与分支命名
- 在 PR review 时自动校验架构约定
- 为新仓库快速套用标准脚手架

## 能力说明

- 定义 commit、分支、目录结构的标准模板
- 提供架构层级(分层、模块边界)的校验规则
- 可与 pre-commit hook / CI 集成自动执行

## 风险与注意事项

规则面向 ECC 生态定制,迁移到其他项目时需要裁剪调整。
