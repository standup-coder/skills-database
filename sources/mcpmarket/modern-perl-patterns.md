# 现代 Perl 模式

> Implements modern Perl 5.36+ idioms and best practices to build robust, maintainable, and secure applications.

## 概述

Modern Perl Patterns 实现现代 Perl 5.36+ 惯用法与最佳实践,帮助构建健壮、可维护、安全的 Perl 应用,适合既有项目现代化改造。

## 使用场景

- 把老旧 Perl 代码升级到现代写法
- 引入 strictures/Moo 等现代模块
- 建立统一的项目模板与编码规范

## 能力说明

- use v5.36+、signatures、postfix deref
- Moo/Moose 轻/重量级 OOP
- 安全:污染模式、参数校验、避免 eval STRING
- 现代测试与打包(Module::Build/Dist::Zilla)

## 风险与注意事项

Perl 招聘困难,长期项目需评估语言选型。
