# Django Celery 集成

> Manages background jobs and asynchronous task scheduling for Django applications using Celery and Redis/RabbitMQ.

## 概述

Django Celery Integration 用 Celery 配合 Redis/RabbitMQ 管理 Django 应用的后台任务与异步调度,聚焦于集成方式与日常运维要点。

## 使用场景

- 把发送邮件、生成报表放入后台
- 使用 Celery beat 调度周期任务
- 跨多个 worker 的任务分发

## 能力说明

- broker/backend 选型与配置
- Django settings 与 Celery app 的整合
- 任务结果存储与查询
- 与 Django signals、ORM 事务的协作

## 风险与注意事项

与 #15(Async Tasks)主题相近,需根据团队需要二选一或组合使用。
