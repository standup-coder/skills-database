# 营销文案

> 撰写高转化营销文案，包括广告、落地页、邮件和社交媒体内容

## 概述

撰写高转化营销文案，包括广告、落地页、邮件和社交媒体内容

### 示例

```
请为 Qoder 撰写落地页文案：
目标受众：独立开发者核心价值：AI 驱动的编码助手差异化：比 Cursor 更智能目标：推动免费试用注册
包含：标题、副标题、3个价值点、CTA
```

## 使用场景

- 撰写广告文案
- 创建落地页内容
- 撰写营销邮件
- 社交媒体帖子
- 产品描述

## 能力说明

- **AIDA 框架**：注意-兴趣-欲望-行动
- **情感触发**：利用心理学原理
- **价值主张**：清晰传达产品价值
- **CTA 优化**：有效的行动号召

## 风险与注意事项

- 了解目标受众痛点
- 保持简洁有力
- 测试不同版本
- 遵循品牌调性
