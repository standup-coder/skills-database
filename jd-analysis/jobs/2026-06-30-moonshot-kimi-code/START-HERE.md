## 一张地图

```
你要掌握的（学）          你要造出的（造）
jd.md  ──────► 要什么（30 分钟读完）
study/00      ─► 差距 + 路线
study/01~06   ─► 6 个维度「为什么学 + 线性步骤 + 验收」
                          practice/m1~m6 ─► 按里程碑一步步造 my-coding-agent
```

**学与造配合**：先扫 study 某维度的「为什么 + 能力清单」→ 打开 practice 对应里程碑照着敲 → 卡住回 study 的「线性路径」细学。

## 线性阅读顺序（核心，照此推进）

1. **Day 1**：读 [jd.md](./jd.md)（搞清这个岗位要什么）
2. **Day 1**：读 [study/00-overview](./study/00-overview.md)（回填能力矩阵当前等级，看差距）
3. **W1-2**：[study/01 工程基础](./study/01-engineering.md) ＋ [practice/m1](./practice/m1-agent-loop.md) → 造出能调工具的 Loop
4. **W1-4**：[study/02 Agent 机制](./study/02-agent-mechanisms.md)（与 01 并行）
5. **W3-4**：[study/03-Ⅰ](./study/03-system-engineering.md) ＋ [practice/m2](./practice/m2-repo-tools.md) → 仓库工具集
6. **W5-6**：[study/03-Ⅱ](./study/03-system-engineering.md) ＋ [practice/m3](./practice/m3-context.md) → 上下文管理
7. **W7-8**：[study/03-Ⅲ](./study/03-system-engineering.md) ＋ [practice/m4](./practice/m4-stability.md) → 稳定性
8. **W9-10**：[study/04 质量进化](./study/04-quality.md) ＋ [practice/m5](./practice/m5-observability-eval.md) → 可观测+评测
9. **全程**：[study/05 产品方法](./study/05-product.md)（每周用 1-2 款工具）
10. **W11-12**：[study/06 软技能](./study/06-soft-skills.md) ＋ [practice/m6](./practice/m6-polish.md) → MCP/Subagent/博客/开源 → **投递**

## 完成 = 投递

> **合格线**：能搭出一个带执行循环、仓库工具、上下文管理、可观测、可评测的 Coding Agent，并能从 trace 里找出它为什么迷路、让它下次不迷路。

各 study/practice 文件末尾都有「出口检验」清单，全 ✅ → 具备竞争力。
