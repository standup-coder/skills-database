## 什么是 Skills Database？

**Skills Database** 是程序员的技能大本营，整合了：

- 📚 **全面的技能树** - 开发者、架构师、测试、运维四大职业路径
- 🔗 **技能生态索引** - 腾讯 SkillHub、Claw Hub、MCP 等技能市场导航
- 🛠️ **实用工具** - 技能追踪、进度管理、学习规划
- 🌐 **多语言支持** - 中英文双语文档

## 5 分钟快速开始

### 1. 选择您的角色

首先确定您的职业方向：

| 角色 | 适合人群 | 核心技能 |
|------|---------|---------|
| [开发者](../dev-skills/overview.md) | 程序员、工程师 | 编程语言、框架、算法 |
| [架构师](../arch-skills/overview.md) | 技术负责人、架构师 | 系统设计、技术选型 |
| [测试](../testing-skills/overview.md) | QA、测试工程师 | 测试策略、自动化 |
| [运维](../ops-skills/overview.md) | DevOps、SRE | 基础设施、CI/CD |

### 2. 评估当前水平

根据经验选择级别：

- **初级** (0-2 年): 掌握基础技能，能完成简单任务
- **中级** (2-4 年): 能独立开发，理解设计模式
- **高级** (4-7 年): 能解决复杂问题，指导他人
- **专家** (7 年+): 架构设计，技术决策，团队领导

### 3. 查看技能清单

点击对应角色的技能清单，开始勾选您已掌握的技能：

- 开发者: [初级](../dev-skills/skills-lists/beginner.md) | [中级](../dev-skills/skills-lists/intermediate.md) | [高级](../dev-skills/skills-lists/advanced.md) | [专家](../dev-skills/skills-lists/expert.md)
- 架构师: [解决方案架构](../arch-skills/skills-lists/solution-arch.md) | [云架构](../arch-skills/skills-lists/cloud-arch.md) | [安全架构](../arch-skills/skills-lists/security-arch.md)
- 测试: [手动测试](../testing-skills/skills-lists/manual-testing.md) | [自动化测试](../testing-skills/skills-lists/test-automation.md) | [性能测试](../testing-skills/skills-lists/performance-testing.md)
- 运维: [基础设施](../ops-skills/skills-lists/infrastructure.md) | [DevOps](../ops-skills/skills-lists/devops.md) | [平台工程](../ops-skills/skills-lists/platform-engineering.md)

### 4. 探索技能生态

发现更多 AI 时代的技能工具：

- [腾讯 SkillHub](../ecosystem/skillhub.md) - 腾讯技能市场
- [Claw Hub](../ecosystem/claw-hub.md) - 龙虾 AI 技能市场
- [MCP Registry](../ecosystem/mcp-registry.md) - Model Context Protocol 技能
- [GitHub Copilot](../ecosystem/github-copilot.md) - AI 编程助手
- [Cursor](../ecosystem/cursor.md) - AI 代码编辑器
- [Lobe Chat](../ecosystem/lobe-chat.md) - 开源 AI 助手市场

## 技能追踪方法

### 方法一：本地 Markdown 编辑

1. Fork 本项目到您的 GitHub 账号
2. 克隆到本地: `git clone https://github.com/YOUR_USERNAME/skills-database.git`
3. 编辑技能清单文件，勾选 `- [x]` 已掌握的技能
4. 提交更改: `git add . && git commit -m "Update my skills" && git push`

### 方法二：使用技能追踪工具

（即将推出）我们将开发在线技能追踪工具，支持：
- 可视化技能树进度
- 生成技能报告
- 学习路径推荐
