## General Questions

### What is Skills Database?

**Skills Database** is a comprehensive skill tree framework for technology professionals. It provides structured learning paths for developers, architects, testers, and operations engineers, while also serving as a hub for AI skill ecosystems.

### Who is this for?

- **Students** learning programming and technology
- **Junior professionals** planning career growth
- **Senior engineers** transitioning to leadership roles
- **Engineering managers** assessing team capabilities
- **HR/recruiters** defining job requirements

### Is it free to use?

Yes! Skills Database is open source under the MIT License. You can use, modify, and distribute it freely.

## Getting Started

### How do I start using Skills Database?

1. Choose your [role](../index.md#role-specific-skills) (Developer, Architect, Tester, or Operations)
2. Select your [experience level](user-guide.md#skill-levels-explained)
3. Review the corresponding skill checklist
4. Start tracking your progress

See our [Quick Start Guide](../getting-started/quick-start.md) for detailed instructions.

### Do I need technical knowledge to use this?

Basic familiarity with GitHub and Markdown is helpful but not required. You can use the web interface to edit files directly.

### Can I use this offline?

Yes! Clone the repository and access all content locally:
```bash
git clone https://github.com/standup-coder/skills-database.git
```

## Skill Trees

### How are skill levels determined?

Skill levels are based on typical industry experience:
- **Beginner**: 0-2 years (learning fundamentals)
- **Intermediate**: 2-4 years (independent contributor)
- **Advanced**: 4-7 years (complex problem solving)
- **Expert**: 7+ years (strategic leadership)

These are guidelines - actual proficiency may vary.

### What if my role combines multiple categories?

Many roles are hybrid. We recommend:
1. Identify your primary role
2. Review secondary role for complementary skills
3. Create a custom skill mix

For example, a "DevOps Engineer" might combine Operations and Developer skills.

### How often are skill trees updated?

We aim to review and update skill trees quarterly. Technology evolves rapidly, and we strive to keep content current.

### Can I suggest new skills?

Absolutely! See our [Contributing Guide](contributing-guide.md) for how to propose additions or changes.

## Progress Tracking

### How do I track my progress?

**Method 1 - GitHub Fork** (Recommended):
1. Fork the repository
2. Edit skill checklists, marking items with `- [x]`
3. Commit your changes

**Method 2 - Local Copy**:
1. Clone locally
2. Edit with any text editor
3. Keep your own version

**Method 3 - Web Editor**:
Use GitHub's edit button on any file.

### Can I export my progress?

Currently, progress is stored in your fork of the repository. We're developing a dedicated tracking tool with export capabilities.

### Is there a visual progress tracker?

Not yet, but it's on our roadmap! We're building a web interface with visual skill trees and progress indicators.

## AI Skill Integration

### What are SkillHub, Claw, and MCP?

These are AI skill marketplaces and protocols:

- **[SkillHub](../ecosystem/skillhub.md)**: Tencent's AI skill marketplace
- **[Claw Hub](../ecosystem/claw-hub.md)**: Lobehub's open AI skill ecosystem
- **[MCP](../ecosystem/mcp-registry.md)**: Model Context Protocol for AI integrations

### How do I use AI skills with this framework?

Each ecosystem page provides:
- Overview of available skills
- Setup instructions
- Integration examples
- Best practices

### Do I need to pay for AI tools?

Some tools are free, others require subscriptions. We clearly mark pricing on each ecosystem page.

## Technical Questions

### What format are skill lists in?

Markdown (`.md`) with checkboxes:
```markdown
- [ ] Skill name - Description
- [x] Completed skill - Description
```

### Can I use this with other tools?

Yes! The simple format makes it compatible with:
- Note-taking apps (Obsidian, Notion)
- Project management tools
- Learning management systems

### Is there an API?

Not currently, but we're planning a JSON API for skill data access.

## Career Questions

### Will this guarantee me a job?

No tool can guarantee employment. Skills Database helps you:
- Identify skill gaps
- Plan learning paths
- Demonstrate capabilities to employers

### How do I transition roles?

See our [User Guide](../getting-started/user-guide.md) for cross-role transition paths. Generally:
1. Identify overlapping skills
2. Learn role-specific fundamentals
3. Build portfolio projects
4. Network in the target community

### Are certifications worth it?

It depends on your region and target employers. We mark certifications as optional and provide alternatives.

## Troubleshooting

### Links not working?

- Ensure you're viewing from the correct directory
- Check if the file exists in your version
- Report broken links via GitHub Issues

### Can't edit files?

- You need a GitHub account to fork
- For local editing, ensure you have write permissions
- Web editing requires the file to exist in your fork

### Something else wrong?

Please [open an issue](https://github.com/standup-coder/skills-database/issues/new) with:
- What you were trying to do
- What happened instead
- Your environment (OS, browser, etc.)
