## 一般问题

### 什么是 Skills4Coder？

**Skills4Coder** 是一个为技术专业人士设计的综合技能树框架。它为开发者、架构师、测试和运维工程师提供结构化学习路径，同时也是 AI 技能生态的枢纽。

### 这适合谁？

- **学生** 学习编程和技术
- **初级专业人士** 规划职业发展
- **资深工程师** 转型到领导角色
- **工程管理者** 评估团队能力
- **HR/招聘人员** 定义职位要求

### 使用是免费的吗？

是的！Skills4Coder 基于 MIT 许可证开源。您可以自由使用、修改和分发。

## 开始使用

### 如何开始使用 Skills4Coder？

1. 选择您的[角色](../index_zh.md#角色特定技能)（开发者、架构师、测试或运维）
2. 选择您的[经验级别](../getting-started/user-guide_zh.md#技能级别说明)
3. 查看相应的技能清单
4. 开始追踪进度

查看我们的[快速上手指南](../getting-started/quick-start_zh.md)获取详细说明。

### 使用这个需要技术知识吗？

熟悉 GitHub 和 Markdown 有帮助但不是必需的。您可以使用网页界面直接编辑文件。

### 可以离线使用吗？

可以！克隆仓库并本地访问所有内容：
```bash
git clone https://github.com/standup-coder/skills4coder.git
```

## 技能树

### 技能级别如何确定？

技能级别基于典型行业经验：
- **初级**: 0-2 年（学习基础）
- **中级**: 2-4 年（独立贡献者）
- **高级**: 4-7 年（复杂问题解决）
- **专家**: 7+ 年（战略领导力）

这些是指南 - 实际熟练程度可能有所不同。

### 如果我的角色结合多个类别怎么办？

许多角色是混合的。我们建议：
1. 确定您的主要角色
2. 查看次要角色获取互补技能
3. 创建自定义技能组合

例如，"DevOps 工程师"可能结合运维和开发者技能。

### 技能树多久更新一次？

我们目标每季度审查和更新技能树。技术快速演进，我们努力保持内容最新。

### 可以建议新技能吗？

当然可以！查看我们的[贡献指南](contributing-guide_zh.md)了解如何提议添加或更改。

## 进度追踪

### 如何追踪进度？

**方法一 - GitHub Fork**（推荐）：
1. Fork 仓库
2. 编辑技能清单，用 `- [x]` 标记项目
3. 提交更改

**方法二 - 本地副本**：
1. 本地克隆
2. 用任何文本编辑器编辑
3. 保留您自己的版本

**方法三 - 网页编辑器**：
使用 GitHub 上任意文件的编辑按钮。

### 可以导出进度吗？

目前，进度存储在您的仓库 fork 中。我们正在开发具有导出功能的专用追踪工具。

### 有可视化进度追踪器吗？

还没有，但在路线图上！我们正在构建带有可视化技能树和进度指示器的网页界面。

## AI 技能整合

### 什么是 SkillHub、Claw 和 MCP？

这些是 AI 技能市场和协议：

- **[SkillHub](../ecosystem/skillhub_zh.md)**: 腾讯的 AI 技能市场
- **[Claw Hub](../ecosystem/claw-hub_zh.md)**: Lobehub 的开放 AI 技能生态
- **[MCP](../ecosystem/mcp-registry_zh.md)**: AI 整合的模型上下文协议

### 如何在此框架中使用 AI 技能？

每个生态页面提供：
- 可用技能概览
- 设置说明
- 整合示例
- 最佳实践

### AI 工具需要付费吗？

有些工具免费，有些需要订阅。我们在每个生态页面清楚标明定价。

## 贡献

### 如何贡献？

我们欢迎贡献！查看我们的[贡献指南](contributing-guide_zh.md)了解：
- 报告问题

## 技术问题

### 技能列表是什么格式？

Markdown (`.md`) 带复选框：
```markdown
- [ ] 技能名称 - 描述
- [x] 已完成技能 - 描述
```

### 可以与其他工具一起使用吗？

可以！简单格式使其兼容：
- 笔记应用（Obsidian、Notion）
- 项目管理工具
- 学习管理系统

### 有 API 吗？

目前没有，但我们计划提供技能数据访问的 JSON API。

## 职业问题

### 这能保证我找到工作吗？

没有工具能保证就业。Skills4Coder 帮助您：
- 识别技能差距
- 规划学习路径
- 向雇主展示能力

### 如何转换角色？

查看我们的[用户指南](../getting-started/user-guide_zh.md)获取跨角色转换路径。一般来说：
1. 识别重叠技能
2. 学习目标角色基础
3. 构建作品集项目
4. 在目标社区建立人脉

### 认证值得吗？

取决于您的地区和目标雇主。我们将认证标记为可选并提供替代方案。

## 故障排除

### 链接不工作？

- 确保从正确目录查看
- 检查文件是否存在于您的版本中
- 通过 GitHub Issues 报告损坏链接

### 无法编辑文件？

- Fork 需要 GitHub 账号
- 本地编辑需要写入权限
- 网页编辑需要文件存在于您的 fork 中

### 其他问题？

请[提交 issue](https://github.com/standup-coder/skills4coder/issues/new)并提供：
- 您尝试做什么
- 实际发生了什么
- 您的环境（操作系统、浏览器等）
