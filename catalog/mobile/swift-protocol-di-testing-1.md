# Swift 协议依赖注入测试(二)

> Implements protocol-based dependency injection to create highly testable Swift code for networking, file systems, and external APIs.

## 概述

Swift Protocol DI Testing(第二版)通过基于协议的依赖注入为网络、文件系统与外部 API 创建高可测的 Swift 代码,与 #22 同名/同主题。

## 使用场景

- 为网络/文件/API 层编写可 mock 的测试
- 提升 SwiftUI 应用的可测性
- 降低外部依赖带来的测试不确定性

## 能力说明

- Protocol-based DI
- URLProtocol / FileManager / API client 的 mock
- 与 XCTest 异步测试结合

与 #22 内容重叠,选用其一即可。
