# Dart 与 Flutter 模式

> Implements production-grade Dart and Flutter architecture patterns for robust and scalable mobile applications.

## 概述

Dart & Flutter Patterns 实现生产级 Dart 与 Flutter 架构模式,面向健壮、可扩展的移动应用,覆盖状态管理、分层与测试。

## 使用场景

- 搭建可扩展的 Flutter 项目骨架
- 统一团队状态管理(BLoC/Riverpod)选择
- 为移动应用建立测试金字塔

## 能力说明

- 分层架构(UI、domain、data)
- 状态管理:BLoC/Riverpod/Provider 模式
- 依赖注入与可测试性
- 平台通道(Platform Channel)最佳实践

## 风险与注意事项

Flutter 版本迭代较快,部分模式需随版本调整。
