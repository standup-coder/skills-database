# Quarkus 安全评审

> Hardens Quarkus applications through standardized authentication, authorization, and secure coding implementations.

## 概述

Quarkus Security Review 通过标准化的认证、授权与安全编码实现来加固 Quarkus 应用,覆盖常见 Web 与 API 安全风险。

## 使用场景

- 为 Quarkus 服务引入 OIDC/JWT 认证
- 审计 API 的权限检查是否完备
- 建立统一的安全编码基线

## 能力说明

- Quarkus Security 扩展(oidc、elytron)
- 基于角色/范围的授权
- 常见漏洞(OWASP Top 10)防护
- 安全审计日志与可观测性

## 风险与注意事项

安全配置错误可能导致拒绝服务或越权,建议结合安全测试与代码审计。
