# ECC 工具成本审计

> Audits and mitigates operational cost spikes, runaway PR creation, and resource leakage in the ECC Tools ecosystem.

## 概述

ECC Tools Cost Audit 审计并缓解 ECC 工具生态中的运营成本飙升、失控 PR 创建与资源泄漏等问题,帮助多代理自动化系统在成本可控的前提下运行。

## 使用场景

- 检测异常 token 消耗与重复任务
- 限制单位时间内可创建的 PR 数量
- 识别泄漏的临时资源(分支、容器)

## 能力说明

- 成本与配额基线定义
- 异常检测规则与告警
- 自动暂停/限流失控代理
- 与监控指标集成输出成本报表

## 风险与注意事项

需要平衡安全限流与正常业务节奏,阈值设置不当可能误杀正常任务。
