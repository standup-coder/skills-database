# Django 验证循环

> Automates a comprehensive 12-phase quality, security, and deployment readiness verification loop for Django applications.

## 概述

Django Verification Loop 为 Django 应用自动化一个 12 阶段的质量、安全与部署就绪验证循环,在每次变更后系统性地确认项目可上线。

## 使用场景

- PR 合并前自动跑完整质量门禁
- 上线前的部署就绪检查清单
- 持续发现安全与配置问题

## 能力说明

- 12 阶段:静态检查、测试、覆盖率、安全扫描、依赖审计、迁移检查、性能基线等
- 失败快速反馈与可定位报告
- 与 CI 平台/部署流水线集成

## 风险与注意事项

全流程耗时较长,建议分级(快速/完整)运行以兼顾速度与覆盖度。
