# Cisco IOS 评审与配置模式

> Provides expert guidance and best practices for reviewing, configuring, and troubleshooting Cisco IOS and IOS-XE network devices.

## 概述

Cisco IOS Review & Configuration Patterns 为 Cisco IOS/IOS-XE 网络设备的评审、配置与故障排查提供专家级指导与最佳实践。

## 使用场景

- 评审现网设备配置的安全与一致性
- 标准化新设备上线模板
- 排查路由/交换/SNMP 故障

## 能力说明

- IOS/IOS-XE 配置结构与最佳实践
- 配置 diff 与合规检查
- 常用 show/debug 命令速查
- 变更管理(rollback、commit confirmed)

## 风险与注意事项

网络配置错误可能造成大面积中断,务必在变更窗口与回退预案就绪后操作。
