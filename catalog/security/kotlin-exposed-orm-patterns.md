# Kotlin Exposed ORM 模式

> Simplifies database access in Kotlin using JetBrains Exposed with production-ready DSL and DAO patterns.

## 概述

Kotlin Exposed ORM Patterns 使用 JetBrains Exposed 简化 Kotlin 数据库访问,提供生产可用的 DSL 与 DAO 模式,兼顾类型安全与表达力。

## 使用场景

- 用 DSL 风格编写类型安全的查询
- DAO 模式组织实体与仓库
- 在 Kotlin 服务中替代 JPA 重型 ORM

## 能力说明

- Exposed DSL(Tables、表达式、join)
- DAO 实体与事务管理
- 与 HikariCP 连接池集成
- 数据库迁移(lisque)协作

## 风险与注意事项

无内置二级缓存,复杂场景需自行实现或与其他工具配合。
