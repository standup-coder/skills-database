# 持续代理循环

> Orchestrates autonomous agent workflows with integrated quality gates and recovery mechanisms for reliable AI-driven development.

## 概述

Continuous Agent Loop 编排自主代理工作流,集成质量门禁与自恢复机制,提供可靠的 AI 驱动开发循环,适合长时间、多步骤任务。

## 使用场景

- 长时间运行的功能实现任务
- 需要自检与回滚的自动化流程
- 在失败时自动重启或切换策略

## 能力说明

- 质量门禁(测试、lint、安全)
- 失败检测与自动恢复/重试
- 可观测的状态机与日志

## 风险与注意事项

长时间自主运行可能累积成本与意外副作用,建议设置预算上限与人工检查点。
