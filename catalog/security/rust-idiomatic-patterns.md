# Rust 惯用模式

> Enforces idiomatic Rust development patterns, memory safety, and high-performance coding standards for robust application building.

## 概述

Rust Idiomatic Patterns 强制 Rust 惯用开发模式、内存安全与高性能编码标准,帮助写出地道、高效、健壮的 Rust 代码。

## 使用场景

- 为团队建立 Rust 编码规范
- 重构非惯用 Rust 写法
- 新成员 Rust 培训

## 能力说明

- 所有权/借用/生命周期惯用法
- 错误处理(Result/Option/?)
- 零成本抽象与性能模式
- clippy 规则与自定义 lint

## 风险与注意事项

严格规范可能限制探索性写法,需在性能关键路径上灵活权衡。
