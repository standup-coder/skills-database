# Gget 生物信息学工具包

> Queries genomic databases and performs sequence analysis using the gget CLI and Python library for rapid bioinformatics research.

## 概述

Gget Bioinformatics Toolkit 使用 gget CLI 与 Python 库查询基因组数据库并执行序列分析,加速生物信息学研究流程。

## 使用场景

- 批量查询基因/蛋白序列与注释
- 比对与提取 ENSEMBL/NCBI 数据
- 构建自动化生信分析流水线

## 能力说明

- gget 子模块:DNA、protein、blast、enrichr 等
- 结构化(JSON)返回便于下游处理
- Python API 与 CLI 双入口

## 风险与注意事项

外部数据库接口可能变更,需关注 gget 版本兼容性。
