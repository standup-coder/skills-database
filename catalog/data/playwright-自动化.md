# Playwright 自动化

> Playwright 浏览器自动化技能，用于端到端测试和 Web 应用交互

## 概述

Playwright 浏览器自动化技能，用于端到端测试和 Web 应用交互

### 示例

- `请编写一个 Playwright 脚本：1. 打开电商网站2. 搜索特定商品3. 添加到购物车4. 截图保存结果5. 导出商品信息`

## 使用场景

- 端到端自动化测试
- 网页爬取和数据抓取
- 自动化表单填写
- 页面截图和 PDF 生成
- 性能测试

## 能力说明

- **多浏览器支持**：Chromium、Firefox、WebKit
- **页面交互**：点击、输入、等待
- **网络拦截**：模拟 API 响应
- **设备仿真**：模拟移动设备视口

## 风险与注意事项

- 使用显式等待而非固定延迟
- 处理弹窗和 iframe
- 注意反爬虫措施
- 设置合理的超时时间
