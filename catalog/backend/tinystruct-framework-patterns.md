# Tinystruct 框架模式

> Accelerates Java application development using the tinystruct framework by providing patterns for dual-mode CLI/HTTP services and native JSON handling.

## 概述

Tinystruct Framework Patterns 借助 tinystruct 框架加速 Java 应用开发,提供 CLI/HTTP 双模式服务与原生 JSON 处理等模式,适合轻量级、模块化项目。

## 使用场景

- 快速搭建同时支持 CLI 与 HTTP 的工具型服务
- 原生 JSON 输入输出的轻量 API
- 学习/演示性质的 Java 微型项目脚手架

## 能力说明

- tinystruct 的模块化组织与生命周期
- 同一套处理器(handler)同时暴露为 CLI 与 HTTP
- 原生 JSON 解析与序列化(无重依赖)

## 风险与注意事项

tinystruct 生态较小众,长期维护与社区支持有限,生产使用需评估风险。
