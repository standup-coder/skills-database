# GitHub 集成

> Manages GitHub pull requests, issues, and CI/CD workflows directly through the command line using the GitHub CLI.

## 概述

GitHub Integration 通过 gh CLI 让 Claude 直接管理仓库的 Pull Request、Issue 与 CI/CD 工作流,是开发者日常与 GitHub 交互的一站式助手。

## 使用场景

- 批量审阅与合并 PR
- 查看与分类 Issue,自动打标签
- 查询 CI 运行状态、重新触发失败任务

## 能力说明

- 完整覆盖 gh CLI 能力:repo、pr、issue、workflow、run 等
- 支持多账户、多仓库批量操作
- 可解析 Actions 日志定位失败原因
- 在 Claude 对话中自然语言驱动 GitHub 操作

## 风险与注意事项

具备写权限,建议限制 Token scope 并在敏感仓库(如生产配置)上设置二次确认。
