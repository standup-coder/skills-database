# Linear 集成

> 使用 MCP 工具管理 Linear 问题和项目，实现工作流自动化

## 概述

使用 MCP 工具管理 Linear 问题和项目，实现工作流自动化

### 示例

```
请在 Linear 中创建以下任务：
项目：Qoder 2.0Sprint：当前 Sprint
任务：1. 实现用户认证模块 [高优先级, 后端]2. 设计新的落地页 [中优先级, 设计]3. 编写 API 文档 [低优先级, 文档]
每个任务包含简要描述。
```

## 使用场景

- Issue 创建和管理
- 项目进度跟踪
- Sprint 规划
- 工作流自动化
- 团队协作

## 能力说明

- **Issue 操作**：创建、更新、关闭
- **项目管理**：查看项目状态
- **标签分类**：自动标签
- **状态流转**：自动化状态变更

## 风险与注意事项

- 需要配置 Linear API key
- 确保项目权限
- 遵循团队工作流规范
- 保持 Issue 描述清晰
