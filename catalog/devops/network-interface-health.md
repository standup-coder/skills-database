# 网络接口健康检查

> Diagnoses and troubleshoots physical network link issues, interface errors, and performance trends across routers, switches, and Linux hosts.

## 概述

Network Interface Health 诊断与排查物理网络链路问题、接口错误与性能趋势,覆盖路由器、交换机与 Linux 主机,是网络运维排障的得力助手。

## 使用场景

- 排查接口 flapping 与丢包
- 分析接口错误计数器(CRC、runts、giants)
- 评估链路带宽利用率趋势

## 能力说明

- Linux:ip、ethtool、ss、sar 等
- 网络设备 show interface 解读
- 性能基线与异常识别

## 风险与注意事项

诊断建议需结合实际拓扑与厂商差异判断。
