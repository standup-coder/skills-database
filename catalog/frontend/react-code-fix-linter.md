# React 代码修复与 Lint

> Automates code formatting and linting checks to ensure code quality and CI compliance before committing.

## 概述

由 Facebook 出品的 React 代码修复与 lint 技能,自动执行代码格式化(Prettier)和静态检查(ESLint),并在提交前确保符合 CI 规范,帮助团队维持一致的代码质量。

## 使用场景

- 提交前自动修复 lint 错误,减少 review 反复
- 统一团队 React 代码风格
- 在 CI 中作为质量门禁运行

## 能力说明

- 集成 ESLint + Prettier 的标准 React 规则集
- 自动修复可自动修复的问题(autofix)
- 检测并提示 React Hooks 使用问题
- 输出 CI 可解析的报告格式

## 风险与注意事项

规则集较严格,可能与既有项目风格冲突;建议先以 warning 模式引入再逐步收紧。
