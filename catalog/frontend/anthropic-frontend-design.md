# Anthropic/frontend-design

> 来源：[VoltAgent/awesome-agent-skills](https://github.com/VoltAgent/awesome-agent-skills) · [技能详情页](https://officialskills.sh/anthropics/skills/frontend-design)

## 概述

A skill for building frontend interfaces with intentional aesthetic direction. It pushes past generic patterns by committing to a specific visual tone before writing a line of code, then implementing that vision with working, production-ready code.
Instead of producing the same purple-gradient-on-white output most AI tools default to, this skill forces a distinct aesthetic commitment upfront and executes it through specific font choices, spatial composition, and motion rather than generic patterns.

**中文名称**：前端设计
**供应商**：anthropics
**分类**：Official Skills / Frontend

## 使用场景

- Building a landing page that avoids the standard gradient-hero-with-Inter-font template
- Styling a React dashboard to match a brutalist or editorial aesthetic instead of a Material UI default
- Generating HTML/CSS layouts with custom typography pairings and motion effects
- Prototyping a web component with scroll-triggered animations and a deliberate color system
- Converting a plain UI mockup into a visually distinct, cohesive page with atmospheric backgrounds
