# 图表制作与可视化

> Generates professional SVG, HTML, and Excalidraw diagrams for software architecture, system flows, and educational concepts.

## 概述

Diagram Maker 是一个 Claude Code 技能,专注于生成专业级的可视化图表。它支持 SVG、HTML 和 Excalidraw 三种主流格式,可用于软件架构图、系统流程图、概念图、白板速写等多种场景。通过自然语言描述即可产出结构清晰、可直接嵌入文档或演示的图表。

## 使用场景

- 为技术文档或 RFC 绘制系统架构图与组件依赖关系
- 生成流程图说明业务逻辑或事件流转
- 为教学或博客内容生成概念图与思维导图
- 用 Excalidraw 风格生成手绘感白板图,适合评审会议

## 能力说明

- 输出格式:SVG(矢量、可缩放)、HTML(可交互)、Excalidraw(可二次编辑)
- 支持图表类型:架构图、流程图、时序图、概念图、ER 图、思维导图等
- 输入为自然语言描述,自动推断节点、边、层级与配色
- 可直接嵌入 Markdown 文档、网页或设计工具
