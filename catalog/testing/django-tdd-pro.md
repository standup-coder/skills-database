# Django TDD 专业版

> Implements rigorous test-driven development workflows for Django applications using pytest and factory_boy.

## 概述

Django TDD Pro 为 Django 应用实现严格的测试驱动开发(TDD)工作流,结合 pytest 与 factory_boy,从红-绿-重构循环到 fixtures 管理全流程覆盖。

## 使用场景

- 为新功能先写测试再实现,保证可测性
- 用 factory_boy 替代静态 fixtures 生成测试数据
- 在 CI 中执行分层测试套件并生成覆盖率报告

## 能力说明

- pytest 项目结构与 conftest 最佳实践
- factory_boy 工厂模式管理测试数据
- Django ORM / DRV 的隔离测试策略
- 覆盖率(coverage)集成与门槛设定

## 风险与注意事项

严格的 TDD 流程在交付压力大的项目中可能影响速度,建议按模块灵活应用。
