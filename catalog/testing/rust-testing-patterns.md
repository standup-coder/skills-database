# Rust 测试模式(二)

> Implements comprehensive Rust testing strategies including unit, integration, and property-based tests following TDD principles.

## 概述

Rust Testing Patterns(第二版)实现全面的 Rust 测试策略,涵盖单元、集成与基于属性的测试,遵循 TDD 原则。与 #18/#30 同主题。

## 使用场景

- 为 Rust 项目建立完整测试体系
- 用 property-based 测试发现边界 bug
- TDD 流程稳健迭代

## 能力说明

- Rust 测试组织与 harness
- proptest/quickcheck 属性测试
- 覆盖率与 CI 集成

## 风险与注意事项

与同主题技能重叠,建议团队统一版本。
