# Quarkus TDD 工作流

> Guides Test-Driven Development for Quarkus 3.x services with specialized support for Apache Camel and event-driven architectures.

## 概述

Quarkus TDD Workflow 为 Quarkus 3.x 服务提供 TDD 指导,特别针对 Apache Camel 集成与事件驱动架构,帮助云原生 Java 服务以测试先行的方式稳健演进。

## 使用场景

- 为 Camel 路由编写单元与集成测试
- 事件驱动服务的契约测试与消费者驱动测试
- Quarkus 应用的原生(native)构建测试

## 能力说明

- Quarkus 3.x 测试注解与 dev 模式集成
- Apache Camel 路由的 Mock与测试工具链
- 事件驱动场景的消息断言与超时控制
- 与 JUnit 5、AssertJ、WireMock 的组合实践

## 风险与注意事项

Camel 与消息中间件测试可能较慢,需要合理拆分测试金字塔层级。
