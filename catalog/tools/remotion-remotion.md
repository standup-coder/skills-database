# Remotion/remotion

> 来源：[VoltAgent/awesome-agent-skills](https://github.com/VoltAgent/awesome-agent-skills) · [技能详情页](https://officialskills.sh/remotion-dev/skills/remotion)

## 概述

Remotion is a framework for creating videos programmatically using React. You write components and animations in code, then render them to MP4 or other formats. It covers compositing, sequencing, audio, captions, 3D, and data-driven visuals.
Writing video logic in React means you can use version control, props, conditionals, and loops instead of manually keyframing in a timeline editor.

**中文名称**：Remotion 视频生成
**供应商**：remotion

## 使用场景

- Generating personalized video messages from a user database
- Adding synchronized captions to a video using React components
- Building animated chart videos that update from live data
- Compositing a green screen recording with a custom background in code
- Rendering a voiceover-narrated explainer video from a script
