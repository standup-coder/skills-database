# Firebase/firebase-basics

> 来源：[VoltAgent/awesome-agent-skills](https://github.com/VoltAgent/awesome-agent-skills) · [技能详情页](https://officialskills.sh/firebase/skills/firebase-basics)

## 概述

Handles the full Firebase setup and day-to-day workflow: CLI installation, authentication, project creation, and running commands. It also covers connecting to Firebase services through MCP tools and keeping your environment current.
It walks through every step from first install to running commands, so you don't have to piece together docs across multiple Firebase guides.

**中文名称**：Firebase 基础
**供应商**：firebase
**分类**：Mobile / Backend

## 使用场景

- Setting up a new Firebase project from scratch in the terminal
- Logging into Firebase on a remote server without a browser
- Switching between multiple Firebase projects during development
- Troubleshooting a broken Firebase CLI installation after an update
- Adding a new Firebase service like Hosting or Firestore to an existing project
