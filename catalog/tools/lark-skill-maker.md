## 使用场景

## 能力说明

基于 lark-cli 创建新 Skill。Skill = 一份 `SKILL.md`，教 AI 用 CLI 命令完成任务。
```
lark-cli             # 已注册 API
lark-cli  +                      # Shortcut（高级封装）
lark-cli api
[--data/--params]  # 任意飞书 OpenAPI
lark-cli schema        # 查参数定义
```
优先级：Shortcut > 已注册 API > `api` 裸调。
