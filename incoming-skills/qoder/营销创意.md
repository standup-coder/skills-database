# 营销创意

> 生成创意营销想法和增长策略，突破思维瓶颈

## 概述

生成创意营销想法和增长策略，突破思维瓶颈

### 示例

```
我需要为 Qoder 进行营销创意头脑风暴：
现状：- 月活用户：5000- 获客成本：$50- 主要渠道：自然搜索
目标：3 个月内用户翻倍
提供 10 个创意营销想法，按潜在影响力排序。
```

## 使用场景

- 营销头脑风暴
- 增长策略探索
- 创意活动策划
- 差异化定位
- 突破增长瓶颈

## 能力说明

- **创意生成**：多角度营销想法
- **可行性评估**：资源和实施难度
- **案例参考**：成功案例启发
- **优先级建议**：潜在影响力排序

## 风险与注意事项

- 想法应该可执行
- 考虑资源限制
- 保持品牌一致性
- 可以小规模测试开始
