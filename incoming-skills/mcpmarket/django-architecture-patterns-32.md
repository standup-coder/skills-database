# Django 架构模式(二)

> Implements production-grade Django architecture, REST API design, and ORM best practices for scalable applications.

## 概述

Django Architecture Patterns(第二版)实现生产级 Django 架构、REST API 设计与 ORM 最佳实践,与 #27 同名,可视为另一作者/视角的版本。

- 搭建新 Django 项目的标准分层
- 重构既有项目的耦合模块
- 提升 ORM 查询与 API 性能

- 领域驱动分层与服务层模式
- DRF 序列化、分页、过滤、缓存
