# Rust 测试模式与 TDD

> Implements comprehensive Rust testing workflows including unit, integration, and property-based testing following TDD methodologies.

## 概述

Rust Testing Patterns & TDD 实现全面的 Rust 测试工作流,在 TDD 方法论下覆盖单元、集成与基于属性的测试。与 #18/43 主题相近,可互为参考。

## 使用场景

- 严格 TDD 流程开发 Rust 模块
- 建立可重复的回归测试集
- 用 property-based 测试发现边界 bug

## 能力说明

- Rust 测试目录组织(tests/ 与 #[cfg(test)])
- proptest/quickcheck 集成
- 测试金字塔分层与 CI 编排

## 风险与注意事项

与同系列技能存在重叠,建议团队统一选用一个版本以避免混乱。
